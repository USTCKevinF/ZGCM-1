# Public Data Categories

## Code

- GitHub source code
- Synthetic cleaned code
- Code reasoning and FIM
- Binary function search
- Software engineering tasks

## Web and Web QA

- Web text and question answering

## Agentic trajectories

- Tool-use and coding-agent trajectories
- Environment-native coding trajectories
- Deep-research and long-context agent traces
- Terminal and tool-calling corpora

## Instruction

- Open-source instruction datasets (Tulu / FLAN style)

## Math

- Competition and textbook-style mathematics
- Synthetic math problems and solutions
- Verifiable mathematical reasoning

## Reasoning

- General reasoning traces
- Full-thought and verifiable reasoning
- Multidomain and structured reasoning
- Teacher-rewritten reasoning data

## Cross-category processing

- Sensitive-content scanning and replacement checks
- Source, revision, license, and checksum registration
- Schema, environment, and dependency locking
- Manifests, statistics, sampling, and validation
- Tokenization, length bucketing, sampling, and mixture construction

The inventory is a category guide, not a fixed dataset manifest. Each dataset still receives an independent AI-generated profile and adapter.
